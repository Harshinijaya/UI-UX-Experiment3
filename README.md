# UI-UX-Experiment3

## Aim:
To redesign the Meesho mobile application using Figma with an attractive, user-friendly interface, improving the shopping experience through better navigation, product display, and interactive UI elements.
## Algorithm:
1. Open Figma and create a new design file.
2. Select the iPhone 14 & 15 Pro Max frame.
3. Design the Meesho home page with a logo, search bar, notification icon, and promotional banner.
4. Add product categories such as Women Fashion, Men Fashion, Home & Kitchen, and Beauty.
5. Create a Deals of the Day section with product images, prices, and discount offers.
6. Design the product details page with product images, ratings, price, and offers.
7. Add size selection, wishlist, and Add to Cart buttons.
8. Apply suitable colours, fonts, icons, and spacing.
9. Preview the redesigned screens and make necessary adjustments.
